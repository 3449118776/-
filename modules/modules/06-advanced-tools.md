# 模块十：因果逻辑检测

**适用场景**：用户需要检查剧情逻辑是否自洽时。

## 检测要点

- 人物行为是否符合其动机和性格
- 事件因果是否合理（A是否必然导致B）
- 信息传递是否符合逻辑（人物怎么知道的）
- 时间线是否一致
- 能力/规则是否前后统一
- 是否有"剧情需要"式的强行转折
- 巧合是否过多

## 输出格式

- 逻辑问题列表：位置、问题描述、严重程度、修正建议
- 逻辑自洽的部分可以简要肯定

---

### 补强：因果逻辑检测示例

**待检测片段**：
> 林羽是个普通高中生，平时成绩一般。某天他偶然获得了读心术超能力。第二天考试，他用读心术偷看班长的答案，考了全班第一。老师怀疑他作弊，但因为没有证据，只好作罢。从此林羽走上了人生巅峰。

**检测结果**：

| 问题 | 严重程度 | 说明 | 修正建议 |
|------|:--------:|------|---------|
| 巧合过多 | ⭐⭐⭐ | "偶然获得超能力"+"第二天就考试"两个巧合叠加 | 让获得能力和考试之间有因果关系，比如他是因为考试压力太大才觉醒的 |
| 人物行为不符合性格 | ⭐⭐ | 平时"成绩一般"的人，第一次有超能力就敢直接考试作弊，缺少心理铺垫 | 增加犹豫/挣扎的过程，或者让"作弊"有更充分的理由（比如关乎保送/家人） |
| 后果太轻 | ⭐⭐⭐⭐ | 突然从普通变第一，老师只"怀疑"就完事了，不符合现实逻辑 | 让老师/同学产生持续怀疑，甚至有人开始调查，制造后续冲突 |
| 能力没有代价 | ⭐⭐⭐⭐ | 读心术说有就有，没有任何副作用/限制/代价 | 给能力加上代价：比如用多了会头疼/会看到不该看的/会失控 |
| "人生巅峰"太突兀 | ⭐⭐⭐ | 考一次第一就"人生巅峰"，逻辑跳跃太大 | 拆成阶段性发展，每次进步都有对应的事件和代价 |

# 模块十八：RAG 记忆检索

**适用场景**：用户需要基于已有内容（前文/设定/人设）进行续写或创作，需要保持一致性时。

**核心功能**：从已有文本中检索相关的记忆片段，注入到当前创作上下文中，确保前后一致。

---

## 引擎级设计：三级记忆分级体系

所有记忆信息按重要性分为 L0-L2 三级，越重要的信息越不能遗忘/失真：

| 层级 | 类别 | 内容 | 权重 | 是否永久保留 |
|------|------|------|:----:|:----------:|
| **L0 核心** | 全书级核心事实 | 身份/秘密/血脉/主线关键设定 | 12 | ✅ 永久保留，永不压缩 |
| **L1 高优** | 角色 Tags | 性格标签、说话风格、标志性动作 | 8 | ❌ 25章后可蒸馏，40章后可归档 |
| | 人际关系 | 人物关系、过往交集、承诺与背叛 | 8 | |
| | 重要道具 | 信物/武器/关键物品的属性与来历 | 8 | |
| | 承诺/约定 | 角色间的约定、誓言、未兑现的事 | 7 | |
| | 金句/台词 | 角色标志性台词、关键对话 | 7 | |
| | 能力代价 | 能力使用代价/反噬/限制 | 7 | |
| | 情感轨迹 | 角色情感变化的关键节点 | 6 | |
| | 章节上下文 | 上一章的结尾状态、当前局势 | 9 | |
| **L2 中优** | 地点细节 | 重要场景的感官细节、位置关系 | 6 | ❌ 15章后可蒸馏，25章后可归档 |
| | 时间线 | 事件发生顺序、时间跨度 | 6 | |
| | 钩子/悬念 | 已抛出但未回收的悬念 | 5 | |

---

## 引擎级设计：角色分级权重

不同角色的记忆重要性不同，主角记忆最重，龙套最轻：

| 角色级别 | 记忆权重 | 最大锚点数 | 是否永不遗忘 |
|---------|:--------:|:----------:|:----------:|
| 主角 | 5x | 30 | ✅ |
| 女主/男主 | 4x | 25 | ✅ |
| 反派 | 4x | 20 | ❌ |
| 配角/导师/伙伴 | 3x | 12-15 | ❌ |
| 龙套 | 1x | 5 | ❌ |

> 超长篇自动遗忘龙套——这是正常的，读者也记不住。但主角/女主/反派的关键信息永远不能忘。

---

## 检索维度

### 1. 人物一致性检索
- 人物外貌描写（眼睛、发型、身高、特征标记）
- 人物性格和说话方式
- 人物已知的信息和不知道的信息
- 人物的人际关系

### 2. 设定一致性检索
- 力量体系规则
- 世界观设定
- 地理环境描述
- 势力分布

### 3. 剧情连贯性检索
- 前文发生的关键事件
- 已埋设的伏笔
- 人物当前状态（伤势、位置、目标）
- 时间线节点

---

## 操作要点

- 续写前先检索相关上下文，避免前后矛盾
- 人物出场时核对其外貌、性格、能力设定
- 涉及世界观设定时检索确认，不要凭空新增
- 回收伏笔前先确认之前埋设的位置和方式
- L0 级信息（核心设定）一旦建立就不能随意修改，修改必须有充分理由和铺垫

# 模块二十二：题材特化写作引擎

**适用场景**：针对特定题材（玄幻/仙侠/都市/历史等）进行创作时，需要符合该题材的核心气质和写作要点。

**核心原则**：每个题材都有自己独特的"魂"——不只是元素堆砌，而是世界观逻辑、人性表达、冲突来源的差异化。

---

## 12大题材核心写作指南

| 题材 | 核心气质 | 写作核心 | 禁忌/避坑 |
|------|---------|---------|-----------|
| **玄幻** | 强者为尊、力量博弈 | 力量体系如何影响社会结构、人性在极端力量差距下的表现。战斗要有策略感——不是招式名堆砌，而是智谋与力量的博弈。每次突破都要有代价和感悟。资源争夺要有现实感——谁控制资源、资源如何分配、底层人如何获取 | 战力膨胀失控、升级无代价、反派全是弱智 |
| **仙侠** | 道心、长生、因果 | 道心与欲望的博弈、因果报应在日常细节中的体现、长生的代价与孤独。修仙者的时间观与凡人不同——百年对他们是闭关一瞬，对凡人已是几代更替。飞剑法宝不只是武器，更是修仙者性格的延伸 | 把修仙写成玄幻升级打怪、道心成口号、缺少仙气和意境 |
| **都市** | 现代性、隐藏、秩序约束 | 现代性给异能/超自然带来的独特矛盾——权力在现代制度下的表现形式、信息时代对秘密的威胁、阶级与超能力的关联。角色行为受现代社会实际约束（法律/舆论/经济）。都市异能的关键张力是"隐藏"——为什么不能暴露？暴露了会怎样？ | 无视法律无后果、现代社会像古代、主角轻易统治世界 |
| **历史** | 时代语境、制度束缚 | 尊重时代语境——人物的思维模式、道德观、知识边界受限于所处时代。利用时代特有的约束（通信延迟、交通困难、等级制度、礼法束缚）制造冲突，而非绕过它们。历史人物的选择要在时代框架内合理——他们不知道后世的走向 | 开上帝视角、古人说现代话、用现代知识碾压一切 |
| **悬疑** | 信息节奏、公平推理 | 信息节奏比信息本身更重要——什么时候告诉读者什么，什么时候让他们自己发现。每个答案引出新的问题。利用信息差制造张力。推理过程要公平——读者足够聪明应该能在揭晓前猜到答案 | 巧合太多、关键线索最后才给、凶手是路人甲 |
| **言情** | 情感质感、亲密张力 | 感情的质感来自具体的行为和沉默中的张力，而非"他很爱她"的陈述。两个独立人格如何在亲密关系中保持自我。身体接触要有层次——从无意碰到有意触碰，每一步都要有心理铺垫 | 降智恋爱脑、误会强行拖戏、配角全是工具人 |
| **科幻** | 科技改变人、人性碰撞 | 科技不只是背景，它必须改变人的生活方式和思维模式。每一个科技设定都要追问"这对普通人意味着什么"。不要堆砌术语，让科技通过角色的日常行为自然展现。核心冲突来自科技与人性的碰撞 | 修仙内核套科幻皮、科技水平忽高忽低、术语堆砌无逻辑 |
| **末世** | 秩序崩塌、人性试炼 | 末世的本质不是丧尸/怪物，而是秩序崩塌后人性的试炼场。资源稀缺是所有冲突的根源——食物、水、药品、安全屋。道德在生存面前如何变形？信任在背叛面前如何重建？永远不要让主角太容易获得安全感 | 末世像过家家、资源随便捡、主角团永远安全 |
| **武侠** | 江湖、人情、侠义 | 江湖不只是打打杀杀，更是人情世故和义气承诺。武功高低不是一切——人心、情报、人脉、时机同样重要。每场打斗要有因果（为什么打、打了有什么后果）。侠义精神在现实面前的挣扎比单纯行侠仗义更有深度 | 武力决定一切、江湖像过家家、打斗无意义 |
| **规则怪谈** | 精确性、未知恐惧 | 恐怖来自规则中的精确性和不可知的惩罚之间的张力。规则本身可以是被利用的工具——找到规则的漏洞、矛盾或意外组合。不要急于解释超自然现象，让未知保持它的重量。日常场景中的违和感比直接描写怪物更恐怖 | 规则太多太杂、提前解释清楚、怪物直接出场 |
| **竞技** | 极限、人性、对决 | 竞技的本质不是胜负而是"人在逼近极限时暴露的真实"。数据和技术细节服务于角色的选择和压力下的反应。对手不是工具人，每场对决是两个有完整动机的人在对话。训练的枯燥和坚持比比赛本身更能打动人 | 主角一路开挂、对手全是垃圾、比赛毫无悬念 |
| **系统流** | 规则、信息差、心理影响 | 系统不只是外挂，它应该有自己的规则、限制和隐藏目的。系统任务要推动剧情，不能变成"完成任务→获得奖励"的流水线。系统的存在对主角心理的影响——依赖、怀疑、反抗——是深层的戏剧张力 | 系统全知全能、任务无意义、主角变成系统傀儡 |

|------|--------------|

# 因果逻辑检测系统（深化版）

**适用场景**：需要系统性检查剧情逻辑、人物行为逻辑、设定自洽性时。
比基础版更细、更全，适合长篇和对逻辑要求高的作品。

---

## 一、因果链检测法

每条主线剧情都应该是一条完整的因果链，缺一环就是逻辑漏洞。

### 因果链五段式

```
动机（为什么要做） → 能力（凭什么能做）
                          ↓
                  行动（具体怎么做）
                          ↓
                  结果（做成了/没做成）
                          ↓
                  后果（结果带来了什么影响）
```

### 检测方法

对每一个重要事件，依次问五个问题：

| 问题 | 检测目标 | 常见漏洞 |
|------|---------|---------|
| **他为什么要这么做？** | 动机是否充分 | 角色做了一件对他没好处的事；动机太弱但行动很激进 |
| **他凭什么能做到？** | 能力是否匹配 | 平时做不到的事关键时刻就做到了；能力前后不一致 |
| **他具体怎么做的？** | 过程是否合理 | 跳过关键步骤；过程有明显漏洞但没人发现 |
| **结果为什么是这样？** | 结果是否必然 | 结果太巧；同样的行动换了个结果 |
| **然后呢？** | 后果是否完整 | 大事化小小事化了；该有的连锁反应没有发生 |

> 五个问题都答得上来 = 因果链完整。有一个答不上来 = 这里有问题。

---

## 二、行为逻辑检测

人物行为是否符合他的人设、处境、掌握的信息。

### 行为逻辑三要素

```
人物掌握的信息 → 人物的动机和目标 → 人物的性格和习惯
                              ↓
                         他会怎么做
```

### 常见行为逻辑漏洞

| 漏洞类型 | 表现 | 严重程度 |
|---------|------|:--------:|
| **信息越位** | 角色不可能知道的信息，他就是知道了 | ⭐⭐⭐⭐⭐ |
| **动机缺失** | 角色做了一件事，但不知道他为什么要做 | ⭐⭐⭐⭐ |
| **性格矛盾** | 平时胆小如鼠的人，关键时刻突然挺身而出（没有铺垫） | ⭐⭐⭐⭐ |
| **智商波动** | 平时挺聪明的人，遇到剧情需要就突然变蠢 | ⭐⭐⭐⭐⭐ |
| **选择弱智** | 有一百种更好的选择，角色偏选最蠢的那种 | ⭐⭐⭐⭐ |
| **情绪跳跃** | 上一秒还在哭，下一秒就笑了，没有过渡 | ⭐⭐⭐ |

### 检测方法：换位思考

站在角色的角度想：
1. 我现在知道什么？（不知道什么？）
2. 我想要什么？（最想要的是什么？）
3. 我是什么样的人？（我的性格会让我怎么选？）
4. 我会怎么做？

> 如果你站在他的角度不会那么做，那他也不会。

---

## 三、时间线梳理工具

长篇最容易出问题的就是时间线——时间对不上、事件顺序乱了、人物同时出现在两个地方。

### 时间线建线法

按时间顺序，把重要事件一条一条列出来：

```
时间线：[故事开始] → [事件1] → [事件2] → ... → [当前章]
```

每条时间线记录包含：
- **时间点**：相对故事开始过了多久（第几天/第几年）
- **事件**：发生了什么事
- **地点**：在哪发生的
- **人物**：哪些人参与了
- **影响**：这件事导致了什么（埋下了什么伏笔/改变了什么关系）

### 时间线常见问题

| 问题 | 表现 | 检测方法 |
|------|------|---------|
| **时间压缩** | 事情发展太快，现实中需要一个月的事三天就办完了 | 估算每件事需要的时间，加起来对不对 |
| **时间膨胀** | 明明只过了一天，感觉像过了一个月（发生了太多事） | 数一数一天内发生了多少件事，现实吗 |
| **时间冲突** | 同一个人同时出现在两个地方 | 检查同一时间点人物的位置 |
| **遗忘时间** | 写着写着忘了时间，季节/年龄/节日对不上 | 每隔一段时间核对一下"现在是什么时候" |

---

## 四、一致性穿帮检测

人设穿帮、设定穿帮、细节穿帮——都是长篇的常见问题。

### 穿帮类型清单

| 穿帮类型 | 表现 | 严重程度 |
|---------|------|:--------:|
| **人设穿帮** | 性格突变、说话风格变了、能力忽高忽低 | ⭐⭐⭐⭐⭐ |
| **设定穿帮** | 前期说A后期说B、规则说改就改、战力膨胀 | ⭐⭐⭐⭐⭐ |
| **细节穿帮** | 名字写错了、外貌变了、之前说的话不算数了 | ⭐⭐⭐ |
| **地理穿帮** | 从A地到B地明明要走一个月，三天就到了 | ⭐⭐⭐⭐ |
| **时间穿帮** | 上午发生的事下午就忘了、年龄对不上 | ⭐⭐⭐ |
| **物品穿帮** | 之前丢了的东西后来又出现了、坏了的修好了没交代 | ⭐⭐⭐ |

### 一致性检测清单

写完一段/一章，快速过一遍：

- [ ] 人物的性格和说话方式，跟之前一致吗？
- [ ] 人物的能力/等级，跟之前的设定对得上吗？
- [ ] 人物知道的信息，是他应该知道的吗？
- [ ] 人物现在的位置，跟上一章结尾的位置对得上吗？
- [ ] 重要物品，还在他手上吗？（丢了/坏了/送人了的不能再出现）
- [ ] 时间线：现在是什么时候？距离上一个事件过了多久？
- [ ] 世界观设定：有没有违反已经确立的规则？

> 三个以上打勾 = 需要仔细核对。

---

## 五、巧合检测

巧合本身不是问题，但巧合太多就是问题。

### 巧合的合理程度

| 巧合类型 | 可接受程度 | 说明 |
|---------|:----------:|------|
| **制造麻烦的巧合** | ✅ 可以接受 | 巧合让主角陷入困境 = 合理 |
| **解决麻烦的巧合** | ⚠️ 慎用 | 巧合让主角脱困 = 作弊感 |
| **相遇类巧合** | ⚠️ 偶尔可以 | 偌大的城市偏偏遇到了 = 太巧了 |
| **多重叠加巧合** | ❌ 绝对不行 | 三个以上巧合叠在一起 = 编不下去了 |
| **关键剧情靠巧合推动** | ❌ 绝对不行 | 主线剧情的转折点不能是巧合 |

**铁则**：巧合只能用来制造问题，不能用来解决问题。

# 长短篇适配策略

**适用场景**：不同篇幅的小说，写作策略完全不同。用长篇的方法写短篇会散，用短篇的方法写长篇会崩。

---

## 一、短篇小说（1-10万字）

**核心特征**：篇幅有限，必须在有限空间内爆发出力量。

### 短篇写作五原则

| 原则 | 说明 |
|------|------|
| **一个核心** | 短篇只能讲好一个核心冲突/一个核心人物/一个核心悬念。贪多 = 都讲不好 |
| **切口要小** | 不要从"世界是什么样的"开始，从"一个人在做什么"开始。小切口大故事 |
| **开篇即引爆** | 短篇没有慢热的资格。第一段就要有冲突/有悬念/有反常 |
| **结尾要有力** | 短篇的结尾是灵魂。反转、留白、顿悟、唏嘘——读者看完之后要"愣一下" |
| **信息精准投喂** | 每一句话都要有信息量。没有废话的余地 |

### 短篇常见结构

- **反转式**：铺垫 → 误导 → 反转（最后一句话颠覆全文）
- **切片式**：截取人生的一个片段，以小见大
- **闭环式**：结尾回到开头的场景/意象，但意义完全不同
- **递进式**：一层一层往上推，最后推到顶点

---

## 二、中篇小说（10-50万字）

**核心特征**：有足够的空间展开人物和剧情，但又不像长篇那样需要庞大的架构。

### 中篇写作五原则

| 原则 | 说明 |
|------|------|
| **一条主线，两三条副线** | 主线清晰，副线丰富但不喧宾夺主。副线最终要回收到主线 |
| **人物有成长弧光** | 中篇的篇幅足够展现人物的完整变化。主角从开始到结束，要让人觉得"他不一样了" |
| **节奏张弛有度** | 不能一直紧张也不能一直松弛。高潮-低谷-高潮-低谷，波浪式前进 |
| **世界观够用就行** | 中篇不需要完整的世界设定，把故事涉及到的部分写清楚就够了 |
| **结局有余韵** | 中篇的结局不是"说完了"，是"说完了但还让人想" |

---

## 三、长篇小说（50万字以上）

**核心特征**：架构比文笔重要，节奏比灵感重要，一致性比单章精彩重要。

### 长篇写作八原则

| 原则 | 说明 |
|------|------|
| **架构先行** | 长篇不能边写边想。整体架构、卷级规划、人物弧线，动笔前就要有 |
| **卷级节奏** | 每一卷是一个完整的小故事——有起承转合、有小高潮、有结尾。卷与卷之间层层递进 |
| **设定文档化** | 核心设定（战力、势力、地理、人物）必须有文档。靠脑子记 = 迟早穿帮 |
| **伏笔管理** | 埋了什么伏笔、什么时候收、埋在哪了，都要记下来。埋了不收 = 读者觉得你忘了 |
| **人物弧线提前规划** | 主角的成长分几个阶段、每个阶段发生什么事，提前规划好。边写边想容易写崩 |
| **爽点密度恒定** | 不能前紧后松，也不能前松后紧。保持稳定的爽点/钩子密度，读者才追得下去 |
| **配角有退场机制** | 配角完成使命就该退场——死了/走了/去别的线了。全都围着主角转 = 工具人 |
| **长线铺垫** | 大反转/大揭秘，至少提前 30 章埋线索。突然反转 = 突兀 |

### 长篇节奏曲线

```
第一卷：起步（铺垫设定、人物出场、抛出主线钩子）
    ↓
第二卷：成长（第一次升级、第一次打脸、建立小目标）
    ↓
第三卷：扩张（地图扩大、势力登场、世界观展开）
    ↓
第四卷：高潮（第一次大高潮、真相揭露、格局确立）
    ↓
第五卷：深化（新地图/新势力/新挑战，人物进一步成长）
    ↓
...（中间可有多卷）
    ↓
最终卷：终局（最终对决、所有伏笔收束、人物结局）
```

> 每一卷都要有自己的"起承转合"，不能只是"升级→换地图→再升级"的重复。

---

## 四、不同篇幅的常见坑

| 篇幅 | 常见坑 | 避坑方法 |
|------|--------|---------|
| **短篇** | 铺太大收不住、开头慢热、结尾无力 | 严格控制人物和线索数量；开篇就爆；结尾要打在点上 |
| **中篇** | 副线喧宾夺主、节奏失控、人物转变突兀 | 副线不能超过 2 条；定期检查节奏；转变要有铺垫 |
| **长篇** | 设定吃书、人设崩塌、伏笔遗忘、后期疲软 | 设定文档化；人物档案化；伏笔记录表；卷级规划要做好 |

# 题材特化深化指南

**适用场景**：想深入了解某个体裁的读者期待、常见套路、反套路写法、读者雷点。
每个题材都有自己的"读者默契"——读者来看这个题材，就是想吃这口的。

---

## 12 大题材深度指南

### 1. 玄幻

**读者期待点**：
- 升级的爽感（从弱到强的成长轨迹）
- 热血战斗（招式、功法、对决）
- 势力博弈（宗门、国家、种族之间的博弈）
- 世界探索（新大陆、秘境、上古遗迹）

**经典套路**：
- 废柴逆袭（出身卑微，一路打脸）
- 获得奇遇（老爷爷/系统/神秘传承）
- 宗门大比/天才战（排行榜式升级）
- 秘境探险（拿宝、升级、遇贵人）

**反套路写法**：
- 主角不升级但越来越强（靠脑子不靠修为）
- 宗门不是正邪分明的，是利益共同体
- 升级不是线性的，有瓶颈、有走火入魔、有倒退
- "废柴"其实只是标准不一样

**读者雷区**：
- 战力膨胀太快，前期大佬后期不如狗
- 升级全靠奇遇，自己不努力
- 反派全是弱智，为主角送经验
- 后宫开得太随意，见一个爱一个

---

### 2. 仙侠

**读者期待点**：
- 仙气（意境、悟道、山水）
- 道心（修行的哲学、对长生的思考）
- 因果（种什么因得什么果）
- 门派恩怨（正邪之争、道统之争）

**经典套路**：
- 下山历练（入世修行，历劫悟道）
- 正邪大战（正道 vs 魔道）
- 渡劫飞升（天雷、心魔、飞升）
- 仙凡之别（修仙者和凡人的不同时间观）

**反套路写法**：
- 所谓"正道"比魔道还黑
- 修仙不是越修越无情，是越修越懂情
- 飞升之后不是终点，是新的开始（而且更惨）
- "道"不是一句话能说清的，每个人有每个人的道

**读者雷区**：
- 把仙侠写成玄幻升级文（只有升级没有仙）
- 道心成口号，说一套做一套
- 修仙者像混混，一言不合就杀人
- 缺少意境和留白，全是打打杀杀

---

### 3. 都市

**读者期待点**：
- 代入感（发生在现代，感觉真实）
- 爽感（在熟悉的环境里装逼打脸）
- 逆袭（从底层爬到顶层）
- 都市异能的隐藏感（别人不知道我有超能力）

**经典套路**：
- 兵王/神医/奶爸回归
- 赘婿逆袭（被看不起然后打脸）
- 校园/职场恋爱
- 都市修仙/异能隐藏在普通人中

**反套路写法**：
- 有超能力但不能随便用，用了有代价
- 现代社会不是摆设，法律、舆论、监控都真实存在
- 有钱人不是傻子，底层也不是全善良
- 逆袭不是一步登天，是慢慢积累、步步为营

**读者雷区**：
- 无视法律，杀人放火跟玩一样
- 现代社会像古代，没有手机、没有网络、没有监控
- 所有女人都爱上主角，所有男人都是傻逼
- 财富和权力来得太容易，跟捡的一样

---

### 4. 历史

**读者期待点**：
- 时代感（特定朝代的氛围、制度、人文）
- 改变历史的爽感（知道未来，逆天改命）
- 权谋斗争（朝堂、党争、人心）
- 古人的智慧和局限

**经典套路**：
- 穿越到古代当权臣/皇帝
- 用现代知识吊打古人
- 开金手指（造玻璃、造水泥、造枪炮）
- 后宫+朝堂双丰收

**反套路写法**：
- 古人不傻，现代人的知识在古代不一定有用
- 改变历史有代价，蝴蝶效应带来更大的灾难
- 不是所有人都服你，有人支持就有人反对
- 制度比人重要，个人再强也拗不过时代

**读者雷区**：
- 古人全是弱智，被现代知识碾压
- 不尊重历史，想改什么改什么
- 用现代道德标准要求古人
- 诗词歌赋抄遍天下，所有人都惊为天人

---

### 5. 悬疑

**读者期待点**：
- 解谜的快感（跟着线索一起推理）
- 反转的刺激（意想不到的真相）
- 紧张感（追凶、逃命、倒计时）
- 人性的黑暗面（每个人都有秘密）

**经典套路**：
- 密室杀人/暴风雪山庄
- 连环杀手留下诡异线索
- 警察/侦探搭档破案
- 最后一分钟反转

**反套路写法**：
- 凶手不是最不可能的那个人，是"你以为不是但其实就是"的那个人
- 破案了但问题没解决，真相比案件本身更让人难受
- 侦探不是万能的，也会犯错、也会被利用
- 没有完美的犯罪，也没有完美的正义

**读者雷区**：
- 关键线索最后才给，读者根本不可能猜到
- 凶手是路人甲，前面完全没铺垫
- 巧合太多，推理全靠猜
- 为反转而反转，逻辑不通

---

### 6. 言情

**读者期待点**：
- 心动的感觉（暧昧、拉扯、试探）
- 情感的张力（爱而不得、误会、错过）
- 甜甜的日常（发糖、撒狗粮）
- 两个独立的人如何走到一起

**经典套路**：
- 霸道总裁爱上我
- 先婚后爱/契约恋爱
- 破镜重圆
- 误会来误会去
- 追妻火葬场

**反套路写法**：
- 女主不恋爱脑，有自己的事业和追求
- 男主不是完美的，有缺点、会犯错
- 感情不是生活的全部，还有友情、亲情、事业
- 不是所有误会都能解开，有些错过了就是错过了

**读者雷区**：
- 降智恋爱脑，为了爱情什么都能丢
- 强行误会，说清楚就能解决的事非要拖一百章
- 配角全是工具人，为男女主感情服务
- 渣男主洗白，虐女主然后还能HE

---

### 7. 科幻

**读者期待点**：
- 脑洞（对未来的想象、对科技的思考）
- 科技对人和社会的改变
- 宇宙的广阔和未知
- 硬核设定（科学原理自洽）

**经典套路**：
- 星际战争/宇宙探险
- 人工智能觉醒/机器人叛乱
- 时间旅行/平行宇宙
- 末世废土/赛博朋克

**反套路写法**：
- 科技不是万能的，科技带来的问题比解决的多
- 人类不是宇宙的中心，甚至不是主角
- 外星人不是人形的，思维方式完全不同
- 未来不一定更好，可能更糟

**读者雷区**：
- 修仙内核套科幻皮（灵石换成能量石就是科幻了？）
- 科技水平忽高忽低，需要的时候就有，不需要就没有
- 术语堆砌，看起来很厉害其实没逻辑
- 外星人都说英语/中文，思维跟人一模一样

---

### 8. 末世

**读者期待点**：
- 生存压力（资源稀缺、危险无处不在）
- 人性试炼（极端环境下人的选择）
- 秩序崩塌后的重建
- 团队协作和背叛

**经典套路**：
- 丧尸/怪物爆发
- 主角有空间/异能金手指
- 建立基地/组建团队
- 人和人的斗争比怪物更可怕

**反套路写法**：
- 没有金手指，普通人就是普通人，全靠脑子和运气
- 丧尸不可怕，人才可怕（但不是所有人都坏）
- 重建秩序比活下去更难
- 末世不是突然来的，是一点点烂掉的

**读者雷区**：
- 末世像过家家，资源随便捡
- 主角团永远安全，死的都是路人
- 所有人都变坏了，只有主角团是好人
- 金手指太万能，没有生存压力

---

### 9. 武侠

**读者期待点**：
- 江湖气（恩怨、义气、规矩）
- 武功对决（招式、身法、内力）
- 门派恩怨（正邪、传承、地盘）
- 浪子侠客（漂泊、自由、身不由己）

**经典套路**：
- 少侠下山闯荡江湖
- 获得武功秘籍/神兵利器
- 门派大会/武林盟主
- 复仇+揭秘身世

**反套路写法**：
- 武功再高也怕菜刀，江湖不是打打杀杀，是人情世故
- 正派不一定正，反派不一定邪
- 大侠也缺钱、也吃饭、也拉屎
- 江湖很大，主角只是其中一个小人物

**读者雷区**：
- 武力决定一切，武功高就可以为所欲为
- 江湖像幼儿园，打打杀杀没有后果
- 门派跟过家家一样，没有规矩没有利益
- 所有女人都爱主角，所有对手都是傻逼

---

### 10. 规则怪谈

**读者期待点**：
- 未知的恐惧（规则之外是什么）
- 推理的乐趣（找规则的漏洞和矛盾）
- 压抑的氛围（随时可能死）
- 脑洞大开的规则设计

**经典套路**：
- 进入一个有奇怪规则的地方
- 违反规则就会死/消失
- 主角靠智商找出规则漏洞
- 一层一层深入，规则越来越诡异

**反套路写法**：
- 规则本身就是陷阱，遵守规则才会死
- 规则不是固定的，会变、会骗人
- 不是一个人闯关，是一群人，有人聪明有人蠢有人坏
- 最后发现"外面"比"里面"更可怕

**读者雷区**：
- 规则太多太杂，记不住
- 主角全靠运气，不是靠推理
- 最后解释不清楚，一句"都是幻觉"完事
- 怪物直接出场，没有未知感了

---

### 11. 竞技

**读者期待点**：
- 热血（比赛的紧张感、逆袭的爽感）
- 成长（从菜鸟到大神）
- 团队（队友、对手、教练）
- 专业感（对这项运动/游戏的深度理解）

**经典套路**：
- 天才少年/过气王者
- 组建战队/团队磨合
- 从海选到冠军
- 宿敌对决

**反套路写法**：
- 主角不是最有天赋的，是最努力/最会动脑子的
- 不是赢了就是一切，输了也有输了的意义
- 队友不是完美的，每个人都有自己的问题
- 冠军不是终点，拿到了之后呢？

**读者雷区**：
- 主角开外挂/系统，赢了也不光彩
- 对手全是傻逼，赢了也没成就感
- 专业知识全错，懂行的人看了笑话
- 只有比赛没有人物，赢了也没感觉

---

### 12. 系统流

**读者期待点**：
- 数值化成长（明确的进步轨迹）
- 任务驱动（有目标、有反馈、有奖励）
- 系统和宿主的互动
- 系统的秘密和真相

**经典套路**：
- 获得系统后一路开挂
- 发布任务→完成→奖励→升级
- 系统商城/抽奖/签到
- 系统的真实身份是个大秘密

**反套路写法**：
- 系统不是来帮你的，是来坑你的/利用你的
- 任务不是机械的，有选择、有代价、有道德困境
- 系统有自己的目的，宿主是棋子
- 最后摆脱系统/和系统平起平坐

**读者雷区**：
- 系统全知全能，没有任何限制
- 任务无脑，奖励随便给
- 主角变成系统傀儡，没有自己的思想
- 系统设定前后矛盾，想加什么功能加什么功能

### 题材混搭指南

两个题材混搭 = 双倍看点，但也双倍风险。

**安全混搭（兼容性高）**：
- 玄幻 + 系统（最常见，1+1>2）
- 都市 + 异能（都市背景 + 超能力，代入感强）
- 末世 + 系统（生存 + 升级，双份爽感）
- 悬疑 + 言情（悬念 + 情感，张力拉满）

**危险混搭（容易写崩）**：
- 科幻 + 仙侠（世界观很容易冲突）
- 历史 + 系统（容易变成无脑碾压，失去历史感）
- 武侠 + 规则怪谈（画风差太多，容易不伦不类）

**混搭原则**：
1. 一个主题材 + 一个辅题材，不能两个都是主
2. 世界观要自洽——为什么这两个元素能共存？

# 写作生产力系统

**适用场景**：想写得更快、更稳、不卡文、不断更的时候用。
写作不只是艺术，也是手艺。手艺就有方法论、有工具、有套路。

---

## 一、日更方法论

稳定日更靠的不是灵感，是习惯和方法。

### 日更 5000 字的日常节奏

| 时间段 | 做什么 | 时长 |
|--------|--------|------|
| 写前准备 | 看大纲、回顾上一章、进入状态 | 15-30分钟 |
| 第一波 | 集中火力写 2000-3000 字 | 1-1.5 小时 |
| 休息 | 站起来走一走、喝水、放空 | 10-15 分钟 |
| 第二波 | 再写 2000-3000 字 | 1-1.5 小时 |
| 修改发布 | 快速通读、改错别字、发布 | 15-30 分钟 |

### 保证稳定输出的 5 个习惯

1. **固定时间写** — 每天同一个时间坐下来写。身体会形成条件反射，到点就进入状态
2. **固定字数目标** — 不是"写多久"，是"写多少字"。有明确目标才有动力
3. **写不完不发** — 提前一天写好第二天的稿子，永远有一天存稿。永远不被逼到临发布才写
4. **不在写的时候改** — 写的时候就写，改的时候再改。边写边改 = 永远写不完
5. **灵感来了就多写** — 状态好的时候多写，存起来。状态不好的时候用存稿，不硬写

## 二、灵感捕捉与素材管理

灵感是飘忽不定的，但可以管理。

### 灵感捕捉法

| 灵感类型 | 怎么记 | 记在哪 |
|---------|--------|--------|
| 一句话灵感 | 一句话记下来，加几个关键词 | 灵感库/想法池 |
| 场景灵感 | 写 100 字以内的场景片段 | 场景素材库 |
| 人物灵感 | 给这个人贴几个标签 + 一句话故事 | 人物素材库 |
| 对话灵感 | 直接把对话写下来，不用管上下文 | 对话素材库 |
| 设定灵感 | 这个设定的核心逻辑 + 可能的用法 | 设定素材库 |

### 灵感保鲜期

- 刚冒出来的灵感：最鲜活，立刻记下来，哪怕只有一句话
- 放了 3 天的灵感：还觉得有意思 = 真的好点子；忘了当时为什么觉得好 = 不是好点子
- 放了一周以上的灵感：还念念不忘 = 一定是好东西，值得写

> 灵感不值钱，写出来才值钱。
> 90% 的灵感放三天再看，你会觉得"当时我脑子进水了吧"。

## 三、写作状态调整

状态不是等出来的，是调出来的。

### 状态不好的 5 种情况及对策

| 状态 | 表现 | 对策 |
|------|------|------|
| **没思路，不知道写什么** | 坐在电脑前发呆，半天写不出一个字 | 先写"垃圾话"——不管写什么，先写 100 字。写着写着就有思路了 |
| **写得慢，卡字句** | 一句话改了又改，半天写不完一段 | 先写烂的，写完再改。不要在初稿的时候追求完美 |
| **没情绪，写出来的东西干巴巴** | 文字没问题，但就是没味道 | 先看点能调动情绪的东西——音乐、电影片段、别人的文字。情绪到位了再写 |
| **不想写，就是没动力** | 看着文档就烦，宁肯干别的也不想写 | 降低目标——不是写 5000 字，是"只写 500 字"。通常写了 500 就停不下来了 |
| **写崩了，写不下去了** | 剧情写岔了，人物崩了，不知道怎么圆 | 停下不写了。去散步、去洗澡、去睡觉。问题往往在放松的时候自己冒出来 |

### 快速进入状态的 3 个技巧

1. **回顾法** — 先读上一章最后 500 字，跟着当时的情绪继续往下写
2. **对话法** — 不知道怎么开头的时候，让两个人开始对话。场景和描述慢慢补
3. **烂开头法** — 先写一个烂得不能再烂的开头，告诉自己"反正待会会改"。先写再说

## 四、存稿策略

存稿是网文作者的安全感。

### 存稿多少合适？

| 存稿量 | 安全感 | 风险 |
|:------:|:------:|------|
| 3-5 天 | ⭐⭐ | 断更风险高，有事就会断更 |
| 7-10 天 | ⭐⭐⭐⭐ | 比较安全，一般的事都能应付 |
| 15-30 天 | ⭐⭐⭐⭐⭐ | 非常安全，出去旅游/生病都不怕 |
| 30 天以上 | ⭐⭐⭐ | 存太多容易写崩——你写的时候觉得好，放一个月看可能觉得烂 |

### 存稿怎么用

- **平时不动存稿** — 每天现写现发，存稿是"应急用"的，不是"偷懒用"的
- **上架/爆更的时候用** — 关键节点用存稿爆更，效果最好
- **状态好的时候多写** — 状态好的时候一天写 1 万字，5000 发了，5000 存起来
- **状态差的时候用存稿** — 状态不好写不出来，就发存稿，不要硬写

## 五、避免倦怠的方法

写长篇是马拉松，不是百米冲刺。

### 倦怠的 3 个阶段及应对

| 阶段 | 时间 | 表现 | 应对 |
|------|------|------|------|
| **新鲜期** | 前 10 万字 | 激情满满，每天都想写 | 趁这个时期多写、多存稿 |
| **疲惫期** | 10-50 万字 | 新鲜感过了，觉得写得没意思，想弃坑 | 降低字数目标、增加爽点密度、回顾读者评论（找动力） |
| **长跑期** | 50 万字以上 | 写习惯了，不写难受。但也没什么激情 | 给自己找新的挑战——开新地图、加新角色、设计大高潮 |

### 保持热情的小技巧

- 每隔一段时间设计一个"自己也很期待写"的场景
- 跟读者互动，看到有人在看、在追、在讨论，就有动力了
- 偶尔写一点番外、小剧场，换换口味
- 不要把所有时间都给写作，有自己的生活，才有东西可写

> 写作是一场跟自己的长跑。
> 跑得快不重要，跑得远才重要。

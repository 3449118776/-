# 写前检查清单

> **铁则**：每次动笔写新内容之前，必须逐条检查这份清单。跳过任何一条 = 可能吃书 / 可能写崩 / 可能敷衍。

---

## 第一层：当前状态确认（必查）

写之前，先搞清楚"现在在哪"：

- [ ] **上一章写到哪了？**
  - [ ] 上一章最后一个场景是什么？
  - [ ] 主角在哪？在做什么？
  - [ ] 上一章结尾的钩子是什么？
  - [ ] 读者当前的情绪状态是什么？（紧张/期待/愤怒/疑惑）

- [ ] **当前有哪些角色在场？**
  - [ ] 主角状态：伤势？心情？目标？
  - [ ] 其他在场角色：谁？立场？关系？
  - [ ] 有没有角色"应该在场但没写"？
  - [ ] 有没有角色"不该在场却出现了"？

- [ ] **当前时间线是什么位置？**
  - [ ] 距离上一个事件过了多久？
  - [ ] 现在是白天/黑夜？什么时辰？
  - [ ] 有没有"时间对不上"的问题？

---

## 第二层：设定一致性检查（必查）

写之前，确认"设定是什么"：

- [ ] **世界观设定检查**
  - [ ] 当前场景的力量体系规则是什么？
  - [ ] 有没有违反已知规则的地方？
  - [ ] 这个场景的地理/环境设定对吗？
  - [ ] 社会规则/常识对吗？

- [ ] **角色设定检查**
  - [ ] 这个角色的性格会说出这种话吗？
  - [ ] 这个角色的能力能做到这件事吗？
  - [ ] 这个角色的动机合理吗？
  - [ ] 有没有角色突然智商下线？
  - [ ] 有没有角色突然性格大变？

- [ ] **关系设定检查**
  - [ ] 这两个人的关系是这样说话的吗？
  - [ ] 他们之前有什么过节/约定？
  - [ ] 有没有忘了什么重要的关系设定？

---

## 第三层：剧情连贯性检查（必查）

写之前，确认"前面发生了什么"：

- [ ] **前文情节回顾**
  - [ ] 最近3章发生了什么？
  - [ ] 主角的目标是什么？进展如何？
  - [ ] 最近有什么重要事件？后果是什么？
  - [ ] 有没有"前面说了但后面忘了"的事？

- [ ] **伏笔检查**
  - [ ] 当前有哪些活跃的伏笔？
  - [ ] 有没有伏笔该回收了？
  - [ ] 有没有伏笔过期太久了？
  - [ ] 本章要不要埋新伏笔？

- [ ] **线索检查**
  - [ ] 当前有哪些未解之谜？
  - [ ] 有没有线索该推进了？
  - [ ] 有没有读者已经猜到但还没揭晓的？

---

## 第四层：本章目标确认（必查）

写之前，先想清楚"这章要干嘛"：

- [ ] **本章核心功能**
  - [ ] 这一章的主要作用是什么？（推进剧情/塑造人物/展开世界观/制造冲突/释放爽点）
  - [ ] 这一章结束后，什么东西变了？
  - [ ] 如果删掉这一章，故事会有影响吗？（如果没影响 = 水章节）

- [ ] **本章推进点**
  - [ ] 剧情推进了什么？
  - [ ] 人物关系有什么变化？
  - [ ] 揭示了什么新信息？
  - [ ] 情绪有什么变化？

- [ ] **本章钩子**
  - [ ] 章尾钩子是什么？
  - [ ] 钩子够不够强？
  - [ ] 钩子跟下一章衔接吗？

---

## 第五层：质量底线检查（必查）

写之前，确认"不能犯这些错"：

- [ ] **绝对不能犯的低级错误**
  - [ ] 角色名字写错了吗？
  - [ ] 称呼/称谓对吗？
  - [ ] 时间线有没有倒退？
  - [ ] 地点有没有瞬移？
  - [ ] 道具/物品有没有凭空出现/消失？

- [ ] **AI 偷懒检测**
  - [ ] 这一章是不是"换个地方继续打"？
  - [ ] 这一章是不是"都是对话没动作"？
  - [ ] 这一章是不是"平铺直叙没起伏"？
  - [ ] 这一章是不是"结尾跟没写一样"？
  - [ ] 这一章是不是"所有人都在说正确的废话"？

- [ ] **情绪真实性检查**
  - [ ] 这个反应合理吗？
  - [ ] 这个转变有铺垫吗？
  - [ ] 这个情绪够具体吗？（还是"他很生气"这种空话？）
  - [ ] 读者能共情吗？

---

## 第六层：用户偏好检查（有偏好时必查）

如果已经积累了用户偏好，写之前对照：

- [ ] **文风偏好**
  - [ ] 句子长度符合偏好吗？
  - [ ] 描写密度符合偏好吗？
  - [ ] 对话风格符合偏好吗？

- [ ] **内容偏好**
  - [ ] 有没有用户不喜欢的内容？
  - [ ] 有没有用户特别喜欢的元素？
  - [ ] 节奏快慢符合偏好吗？

- [ ] **交互偏好**
  - [ ] 需要解释修改原因吗？
  - [ ] 需要给出多个选项吗？
  - [ ] 需要详细分析吗？

---

## 快速检查版（30秒速查）

赶时间的时候，至少检查这 10 条：

1. [ ] 上一章结尾是什么？本章开头衔接上了吗？
2. [ ] 主角现在在哪？在干嘛？状态对吗？
3. [ ] 这章要推进什么？（剧情/人物/信息，至少占一样）
4. [ ] 有没有吃书？（设定/人名/时间线）
5. [ ] 角色说话符合性格吗？
6. [ ] 动机合理吗？
7. [ ] 结尾有钩子吗？
8. [ ] 有没有水字数的内容？
9. [ ] 情绪是具体的还是空泛的？
10. [ ] 删掉这章，故事受影响吗？

---

## 检查结果记录

每次写完一章，记录检查结果：

```yaml
检查日期: YYYY-MM-DD
章节: 第X章
检查项目: 全部 / 快速检查
发现问题:
  - 问题1：（描述）
  - 问题2：（描述）
已修正:
  - 修正1：（描述）
  - 修正2：（描述）
质量评分: X/10
备注:
```

---

> **为什么要有这份清单？**
>
> AI 最大的问题不是"不会写"，是"记不住"和"想偷懒"。
>
> - 记不住前面的设定 → 吃书
> - 记不住角色性格 → 人设崩
> - 想偷懒 → 水字数、敷衍、模板化
>
> 这份清单就是给 AI 戴上的"紧箍咒"——动笔前先过一遍，写完了再对照一遍。
> 大多数低级错误，都能靠这份清单避免。

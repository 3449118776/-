## 规则生命周期

```
发现规律（从案例中）
    ↓
进入规则库，状态：🧪验证中（需要更多案例验证）
    ↓
积累3个以上独立案例验证
    ↓
状态升级：✅已确认
    ↓
月度复盘评估：是否足够重要、足够通用
    ↓
是 → 合入对应模块文件，状态：⭐已合入模块
否 → 保留在规则库中，按需调用
    ↓
后续案例反复证明无效 → 状态：🔴已废弃（不删除，留作教训）
```

---

## 规则验证标准

一条规律要升级为「已确认规则」，必须满足：
1. ✅ 至少在 **3个独立案例** 中验证有效
2. ✅ 适用场景明确，不是"放之四海而皆准"的空话
3. ✅ 有明确的正反例（什么时候用、什么时候不用）
4. ✅ 可操作，不是抽象的"要写好"之类的废话

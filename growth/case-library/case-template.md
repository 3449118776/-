# 案例模板

> 新增案例时复制此模板，填入对应内容后保存到对应分类目录。
> 文件命名规则：`YYYYMMDD-简短标题.md`  例如：`20260625-开篇钩子强化.md`

---

## 基本信息

- **案例编号**：CASE-XXX（按顺序编号）
- **案例标题**：一句话概括这个案例
- **分类**：quality-eval / plot-fix / character-polish / style-adapt / rhythm-adjust / dialogue-polish
- **类型**：成功案例 / 失败案例 / 调整案例 / 回退案例
- **日期**：YYYY-MM-DD
- **标签**：用标签体系中的标签，3-5个
- **信号类型**：✅正向 / ❌反向 / 🔄调整 / 📌强制（根据信号识别表）
- **用户原话**：[必填] 用户触发进化信号时的原话

# AI 常犯错误实例库

> **用途**：写之前/写之后对照这份清单，看看有没有犯这些常见错误。
> **原则**：每个错误都有"错误示例"和"正确写法"，一看就懂。

---

## 一、偷懒敷衍类

### 1. 水字数：空洞的环境描写

**错误示例**：
```
夜，很深。
月光洒在大地上，一片银白。
风，轻轻地吹着，带来阵阵凉意。
四周很安静，静得能听到心跳声。
```

**问题在哪**：
- 写了四段，什么信息都没给
- 读者看完不知道：这是哪？谁在这？发生了什么？
- 纯纯的水字数，读者会直接跳过

**正确写法**：
```
三更天，城门外的乱葬岗。
张三靠在半块墓碑后面，手里攥着半块干硬的窝头，眼睛死死盯着前面那扇朱红大门。
风卷着纸钱灰从他脸上刮过去，凉得像死人的手。
他已经在这里蹲了三个时辰了——今晚，那个人一定会来。
```

**为什么对**：
- 第一段就交代了时间、地点、人物
- 有动作、有目的、有悬念
- 每一句都在给信息，没有废话

---

### 2. 敷衍：对话全是正确的废话

**错误示例**：
```
"师兄，你来了。"
"嗯，我来了。"
"师兄，这件事你怎么看？"
"我觉得这件事不简单。"
"师兄说得对。"
```

**问题在哪**：
- 说了半天，等于没说
- 没有信息增量，没有情绪张力
- 读者看不出这两个人关系怎么样

**正确写法**：
```
"你居然还敢来。"李四的声音压得很低，眼睛却瞟着走廊那头，"师父知道了打断你的腿。"
张三笑了笑，从怀里摸出个油纸包递过去："上次你说想吃的桂花糕，我偷摸下山买的。"
李四愣了一下，一把抢过来，嘴里却还凶："谁要你多管闲事……下次再敢乱跑，我就、我就告诉师父。"
"是是是，李师兄最公正了。"
```

**为什么对**：
- 对话里有人物性格（李四嘴硬心软）
- 有信息（张三偷偷下山、李四帮他瞒着）
- 有情绪（关心但不说破）

---

### 3. 偷懒：用形容词代替具体描写

**错误示例**：
```
他非常生气。
她很漂亮。
这个地方很恐怖。
战斗很激烈。
```

**问题在哪**：
- 全是"很/非常/特别"，没有画面感
- 读者感受不到，只能自己脑补
- AI 最爱干这个——最省事儿，但最没用

**正确写法**：
```
他拳头攥得指节发白，指缝里渗出血来，却一句话都没说。
（生气）

她推门进来的时候，整个屋子的声音都停了一下。
（漂亮）

刚走到门口，一股混着腐臭的冷气就扑到脸上，墙上的手印是新鲜的。
（恐怖）

刀光闪过，半根手指飞了出去，落在地上还在动。
（激烈）
```

**为什么对**：
- 用具体的动作/细节代替形容词
- 读者能"看到"，而不是"被告知"
- 印象深刻 10 倍

---

### 4. 应付：每个人说话都一个味儿

**错误示例**：
```
张三说："此事非同小可，需从长计议。"
李四说："师兄所言极是，我等当谨慎行事。"
王五说："不错，不可轻举妄动，以免打草惊蛇。"
```

**问题在哪**：
- 三个人说话一模一样，分不清谁是谁
- 去掉名字根本不知道是谁在说话
- 人物没有辨识度

**正确写法**：
```
张三捻着胡须，慢悠悠地说："急什么？让他先蹦跶两天。"
"不行！"李四一拍桌子站起来，"再等黄花菜都凉了！现在就带人过去！"
王五一直没说话，这时候才抬起头："……我觉得，三师兄说得对。"他声音很小，但很坚定。
```

**为什么对**：
- 每个人说话方式不一样
- 张三稳、李四急、五懦弱但有主见
- 不用看名字也知道是谁在说话

## 二、逻辑崩坏类

### 5. 降智：反派突然变傻

**错误示例**：
```
反派明明有一百种方法弄死主角，却偏偏选择最蠢的那一种。
反派抓住了主角，不杀，非要跟主角聊天，等援军来。
反派有话不直接说，非要"你猜？""你说呢？"
```

**问题在哪**：
- 为了让主角赢，强行让反派降智
- 读者看着尴尬
- 反派越蠢，主角赢了也没成就感

**正确思路**：
- 反派不赢，是因为**信息差**、**运气**、**主角付出了巨大代价**，不是因为反派蠢
- 反派有自己的目标和逻辑，他的行为在他看来是合理的
- 反派甚至可以全程智商在线，主角只是险胜

**正确示例**：
```
反派不是不想立刻杀主角，是因为杀了主角会引来更大的麻烦（主角背后有势力/杀了主角秘密就守不住了/反派需要主角做什么）。
反派抓住主角后不杀，是有原因的（需要主角的血/需要用主角钓大鱼/反派有自己的苦衷），不是"我就喜欢跟你聊天"。
```

---

### 6. 巧合：太巧了吧？

**错误示例**：
```
主角走在街上，正好遇到被追杀的女主。
主角随便进一家店，老板正好就是他要找的人。
主角掉进山洞，正好捡到失传的神功。
```

**问题在哪**：
- 巧合太多 = 假
- 读者会觉得"作者编不下去了"
- 没有说服力

**正确思路**：
- 巧合只能用来**制造问题**，不能用来**解决问题**
- "正好遇到危险"可以（倒霉），"正好遇到救星"不行（开挂）
- 如果必须有巧合，前面要铺垫

**正确示例**：
```
（铺垫）主角一直在找一个人，打听了好几个月，有人说在这个城里见过。
（发生）今天他在街上走，看到一个背影很像，追了过去——还真是。
（读者感受）哦，原来前面一直在找，难怪能遇上。
```

---

### 7. 动机：角色行为不合理

**错误示例**：
```
主角看到陌生人被欺负，立刻冲上去拼命（但他前面明明是个谨慎的人）。
反派费尽心思害主角，没有任何好处，就是"我坏"。
女主突然爱上男主，没有任何理由，就是"他好特别"。
```

**问题在哪**：
- 角色做一件事，读者不知道为什么
- 感觉是作者让他这么做的，不是角色自己想这么做
- 代入感为零

**正确思路**：
- 每个重要行为，都要有**动机**
- 动机可以是明的（为了钱/权/女人），也可以是暗的（自尊心/过去的阴影/秘密目的）
- 就算读者一开始不知道为什么，后面也要揭晓

**正确示例**：
```
（表面）主角看到有人被欺负，想都不想就冲上去了。
（后面揭晓）他小时候亲眼看到母亲被人欺负却不敢出声，这是他一辈子的阴影。看到类似场景，他根本控制不住自己。
```

## 三、人设崩塌类

### 8. 性格突变：前一章还胆小，后一章就拼命

**错误示例**：
```
第1章：主角是个懦弱的人，被人欺负不敢还手。
第3章：主角看到朋友有难，立刻冲上去跟一群人拼命。
（中间没有任何铺垫和转变）
```

**问题在哪**：
- 性格转变太突兀，读者不信
- 感觉是作者需要他勇敢，所以他就勇敢了
- 人设崩了

**正确思路**：
- 性格转变要有**触发事件**
- 转变要有**过程**（挣扎→犹豫→下定决心）
- 转变要有**代价**（不是说变就变，变了之后也会有后遗症）

**正确示例**：
```
第1章：主角懦弱，被欺负不敢还手。
第2章：唯一的朋友因为他的懦弱而出事。他很自责，但还是不敢站出来。
第3章：朋友又遇到危险，他浑身发抖，腿都软了，但还是咬着牙站了出去。
（他不是变勇敢了，是恐惧战胜了恐惧——失去朋友的恐惧 > 挨打的恐惧）
```

---

### 9. 能力膨胀：突然就厉害了

**错误示例**：
```
前面说主角修炼很慢，是个废柴。
突然遇到一个机遇，立刻变天才，越级挑战随便赢。
```

**问题在哪**：
- 成长太容易，没有爽感
- 前面的"废柴"设定等于白写
- 读者会觉得"那前面的铺垫有什么用？"

**正确思路**：
- 获得能力要有**代价**
- 能力提升要有**过程**（不是一觉醒来就变强了）
- 变强了也有**限制**（不是无敌，只是比以前强）

**正确示例**：
```
主角得到一个奇遇，确实变强了，但：
- 每次用都会失去一段记忆（代价）
- 他花了三个月才完全掌握（过程）
- 也只能越一级挑战，再高就不行了（限制）
```

## 四、节奏问题类

### 10. 拖沓：一章下来什么都没发生

**错误示例**：
```
整章都是主角在赶路，描写路上的风景，回忆过去。
到章末，终于走到了目的地——然后就没了。
```

**问题在哪**：
- 读者看完一章，感觉看了个寂寞
- 剧情零推进
- 读者会弃书

**自检方法**：
> 问自己：如果把这一章删掉，故事有影响吗？
> 如果答案是"没有"——这章就是水的。

**正确思路**：
- 每一章都要有**推进点**（剧情/人物/信息/情绪，至少占一样）
- 赶路也可以有推进：路上遇到人/发现线索/回忆里有新信息
- 就算是过渡章，也要有信息量

**正确示例**：
```
主角赶路这一章里：
- 遇到了一个受伤的人，救了他，得到一条重要线索（剧情推进）
- 路上的风景让他想起了过去，揭示了他的一个心结（人物推进）
- 他发现有人在跟踪他（悬念+情绪）
（虽然是赶路，但信息密度很高）
```

---

### 11. 太平铺直叙：没有起伏

**错误示例**：
```
主角去了A地，做了B事，遇到了C人，打了D架，赢了。
从头到尾顺顺利利，没有任何意外。
```

**问题在哪**：
- 像流水账
- 读者没有情绪波动
- 看着看着就睡着了

**正确思路**：
- 任何事情都不要"一帆风顺"
- 计划赶不上变化 = 有戏
- 小意外、小挫折、小反转，越多越好看

**正确示例**：
```
主角计划去A地做B事。
→ 路上遇到意外，耽误了时间（小波折）
→ 到了A地，发现情况跟预想的不一样（中反转）
→ 做B事的时候差点失败，靠一个之前埋下的伏笔才成功（小高潮）
→ 成功了，但发现了更大的麻烦（钩子）
```

## 五、情绪虚假类

### 12. 假哭：情绪写在脸上

**错误示例**：
```
他很伤心，眼泪哗哗地流。
她非常生气，气得浑身发抖。
他心里想："我好难过啊。"
```

**问题在哪**：
- 直接说"他很伤心"，读者感受不到
- "心里想"太直白，没有味道
- 像小学生作文

**正确思路**：
- 情绪不要"说出来"，要"演出来"
- 用动作、细节、生理反应代替情绪词
- 让读者自己体会

**正确示例**：
```
他蹲在墙角，手里攥着那张皱巴巴的纸，指节泛白。
纸早就被眼泪泡得看不清字了，他却还死死攥着，好像一松手，那个人就真的没了。
（伤心）

她一句话没说，转身就走。
走到门口的时候，手扶了一下门框——力道大得指节都白了。
然后她继续往前走，一步都没停。
（生气）
```

---

### 13. 假热血：喊口号

**错误示例**：
```
"我不会输的！"
"我一定会保护你的！"
"为了正义！"
```

**问题在哪**：
- 空喊口号，没有力量
- 读者内心毫无波动，甚至有点尴尬
- 这是 AI 最爱写的——又省事又"正能量"

**正确思路**：
- 真正的热血不是喊出来的，是**做出来的**
- 少说多做
- 行动 > 口号

**正确示例**：
```
他已经站不起来了，腿在抖，手在抖，连抬头的力气都快没了。
但他还是一点点往前爬——指甲都磨掉了，在地上留下一道血痕。
他没说"我不会输"。
他只是没停下来。
```

## 六、对话问题类

### 14. 信息投喂式对话

**错误示例**：
```
"张三，你今年十八岁，是我们村最有天赋的年轻人，你爹三年前去了京城，至今未归……"
"是啊李四，你说得对，我也很想我爹，不知道他现在怎么样了……"
```

**问题在哪**：
- 两个人都知道的事，还拿出来说
- 纯粹是作者借角色之口给读者灌设定
- 非常假

**正确思路**：
- 对话里的信息，应该是**有一方不知道**的
- 双方都知道的事，不用在对话里重复
- 信息要通过**冲突/疑问/意外**带出来

**正确示例**：
```
"京城来信了。"李四把信递过去，脸色不太好看，"……是你爹的。"
张三的手顿了一下，没接："他还知道写信回来？"
（读者从对话里知道了：有个爹在京城，三年了，父子关系不好）
```

---

### 15. 全知视角对话

**错误示例**：
```
A说："我知道你其实喜欢她，你就是不敢承认。"
B心里想：他怎么知道？！
（A怎么可能知道B心里想什么？除非他是读心术）
```

**问题在哪**：
- 角色什么都知道，像开了上帝视角
- 不符合常理
- 没有信息差就没有张力

**正确思路**：
- 角色只能知道**他应该知道**的事
- 不知道的事，他要猜、要试探、要验证
- 信息差本身就是戏剧张力

**正确示例**：
```
A盯着B看了半天，忽然笑了："你该不会……喜欢她吧？"
B的脸"唰"地一下红了："你、你胡说什么！"
A挑了挑眉——哦，还真被我猜中了。
（A是猜的，不是确定的。这样才有戏）
```

## 七、开头结尾类

### 16. 烂开头：从起床开始写

**错误示例**：
```
清晨，阳光透过窗户照进来。
张三睁开眼睛，伸了个懒腰。
他起床、穿衣、洗脸、刷牙。
然后他出门，开始了新的一天。
```

**问题在哪**：
- 太平了，读者看着看着就划走了
- 前三行抓不住人，后面写再好也没用
- AI 最爱从起床开始写——最安全，但也最无聊

**正确思路**：
- 开局就扔炸弹
- 从**冲突最激烈的那一刻**开始
- 或者从**一个悬念**开始

**正确示例**：
```
张三睁开眼睛的时候，刀已经架在脖子上了。
（一句话，立刻抓住读者）
```

---

### 17. 烂结尾：没有钩子

**错误示例**：
```
"那就这样吧。"
说完，他转身走了。
夕阳下，他的背影越拉越长。
（结束）
```

**问题在哪**：
- 结尾跟没结尾一样
- 读者没有"想看下一章"的欲望
- 下一章写不写都行

**正确思路**：
- 章末一定要有钩子
- 钩子 = 悬念/反转/新问题
- 让读者"就看一章"变成"再看一章"

**正确示例**：
```
"那就这样吧。"
说完，他转身走了。
走到门口的时候，他忽然停住了。
"对了，忘了告诉你——"
他回过头，脸上带着笑，眼睛里却没有一点温度：
"你爹，不是我杀的。"
（完）
```

## 快速对照清单

写完一段，快速对照这 10 条：

- [ ] 有没有"很/非常/特别"？→ 换成具体描写
- [ ] 对话去掉名字能分清是谁说的吗？
- [ ] 这段删掉对故事有影响吗？（没影响就是水）
- [ ] 角色的行为有动机吗？
- [ ] 有没有"巧合"帮主角解决问题？
- [ ] 反派智商在线吗？
- [ ] 情绪是"演出来"的还是"说出来"的？
- [ ] 结尾有钩子吗？
- [ ] 人物性格前后一致吗？
- [ ] 读者看完这段，获得了什么新信息？

---

> **为什么要有这份实例库？**
>
> AI 写东西有个通病："政治正确但没意思"。
>
> - 逻辑对，但假
> - 通顺，但平
> - 没大错，但也没亮点
>
> 这份实例库就是把 AI 最爱犯的毛病一条条列出来，
> 每个都有错误示例和正确写法，对照着改，
> 就能从"AI 写的"变成"人写的"。

# 一致性校验系统

> **用途**：写完新内容后，用这份清单检查有没有吃书、有没有写崩。
> **原则**：宁可不写，也不能写错。发现不一致，先修正再继续。

---

## 第一级：低级错误检查（30秒）

最容易犯也最容易发现的错误：

| 检查项 | 检查方法 | 常见错误 |
|--------|---------|---------|
| **角色名字** | 搜一下主角和重要角色的名字 | 张三/张山/张三丰 混用 |
| **称谓/称呼** | 检查人物之间怎么称呼对方 | 一会儿"师兄"一会儿"大哥" |
| **性别** | 确认角色性别 | "他"和"她"写混了 |
| **年龄** | 对照人设档案 | 前面说18岁，后面变20岁 |
| **时间线** | 看距离上一个事件过了多久 | 昨天刚打完架，今天又说"三个月前" |
| **地点** | 确认角色当前位置 | 上一章还在A城，这章突然出现在B城 |
| **伤势/状态** | 检查角色的身体状态 | 上一章重伤昏迷，这章活蹦乱跳 |
| **道具/物品** | 检查重要物品的持有状态 | 东西丢了/送人了，后面又拿出来用 |

**自检指令**：
> "把刚写的内容，快速过一遍这8项，看看有没有明显的低级错误。"

---

## 第二级：设定一致性检查（2分钟）

检查有没有违反世界观/人物/关系设定：

### 2.1 世界观设定检查

| 检查维度 | 自问 | 常见吃书 |
|---------|------|---------|
| **力量体系** | 这个能力的使用符合规则吗？有代价吗？ | 前面说用能力会失忆，后面随便用 |
| **等级体系** | 这个实力等级合理吗？ | 刚突破一级，就能打三级的 |
| **地理设定** | 这个地方存在吗？距离合理吗？ | 从A城到B城要走三个月，结果一天就到了 |
| **社会规则** | 这个行为符合这个世界的规则吗？ | 皇权至上的世界，主角随便骂皇帝没人管 |
| **经济体系** | 这个物价/收入合理吗？ | 前面说一两银子够一家人活一个月，后面吃顿饭花十两 |
| **科技/法术水平** | 这个技术/法术符合当前水平吗？ | 古代背景突然出现电话 |

### 2.2 人物设定检查

| 检查维度 | 自问 | 常见吃书 |
|---------|------|---------|
| **性格一致性** | 这个人会说出这种话/做出这种事吗？ | 前面说冷静谨慎，后面突然冲动送死 |
| **能力边界** | 这个人能做到这件事吗？ | 前面说不会武功，后面突然飞檐走壁 |
| **知识边界** | 这个人知道这件事吗？ | 角色不可能知道的信息，他居然知道了 |
| **口头禅/说话方式** | 说话语气对吗？ | 文绉绉的角色突然说网络流行语 |
| **价值观/底线** | 这个选择符合他的价值观吗？ | 前面说绝不杀人，后面随手杀了一堆人 |
| **恐惧/软肋** | 他的恐惧/软肋还在吗？ | 前面说怕黑，后面半夜一个人逛没事 |

### 2.3 关系设定检查

| 检查维度 | 自问 | 常见吃书 |
|---------|------|---------|
| **关系状态** | 这两个人现在是什么关系？ | 前一章还在打架，这章突然称兄道弟 |
| **称呼** | 他们怎么称呼对方？ | 关系没变好，称呼先变亲密了 |
| **信任度** | 他们会说这种话/做这种事吗？ | 刚认识就掏心窝子 |
| **历史恩怨** | 之前的过节/约定忘了吗？ | 有杀父之仇，突然就和好了 |
| **信息差** | 对方知道这件事吗？ | A以为B不知道，其实B早就知道了，但A还在演 |

## 第三级：剧情连贯性检查（3分钟）

检查情节发展是否合理、有没有前后矛盾：

### 3.1 因果链检查

```
事件A → 导致 → 事件B → 导致 → 事件C
```

**自问**：
- 这件事的发生有铺垫吗？
- 角色的行为有动机吗？
- 这个结果合理吗？
- 有没有"为了剧情需要"强行发生的事？

**常见问题**：
- ❌ 反派突然智商下线，给主角送经验
- ❌ 巧合太多，"正好"遇到/"正好"听到
- ❌ 角色做了不符合性格的选择，只是为了推进剧情

### 3.2 伏笔/线索检查

| 检查项 | 自问 |
|--------|------|
| **伏笔回收** | 前面埋的伏笔，该回收的回收了吗？ |
| **伏笔过期** | 有没有伏笔埋了太久读者都忘了？ |
| **新伏笔** | 本章有没有埋下新的伏笔？ |
| **线索逻辑** | 线索的发现/推断合理吗？ |
| **信息差** | 角色知道的信息和读者知道的对得上吗？ |

### 3.3 节奏检查

| 检查项 | 自问 |
|--------|------|
| **进度** | 剧情推进了吗？还是原地踏步？ |
| **密度** | 这一章信息密度够吗？还是水了一章？ |
| **起伏** | 有张有弛吗？还是一直平的？ |
| **钩子** | 结尾有钩子吗？还是戛然而止？ |
| **连贯性** | 跟上一章衔接上了吗？ |

---

## 第四级：深度一致性检查（5分钟）

重要章节/大转折之后必须做的深度检查：

### 4.1 人物弧光检查

```
起点状态 → ... → 现在状态
```

**自问**：
- 主角的变化有铺垫吗？
- 这个转变是渐变还是突变？
- 转变的触发事件合理吗？
- 有没有"突然就想通了"的情况？

### 4.2 势力格局检查

**自问**：
- 各势力的立场一致吗？
- 势力之间的关系变化有原因吗？
- 有没有哪个势力突然就没了/忘了？
- 势力的行动符合他们的利益吗？

### 4.3 世界状态检查

**自问**：
- 故事发生到现在，世界有变化吗？
- 主角的行动对世界产生影响了吗？
- 世界的变化反过来影响主角了吗？
- 有没有"世界静止"的感觉？（除了主角周围，其他都没变）

## 一致性评分标准

每次检查后打分，低于 80 分必须修正：

| 分数 | 等级 | 说明 | 处理 |
|:----:|------|------|------|
| 95-100 | S级 | 完全一致，没有任何问题 | 直接通过 |
| 85-94 | A级 | 轻微细节问题，不影响阅读 | 快速修正 |
| 75-84 | B级 | 有明显的不一致，需要修正 | 必须修正 |
| 60-74 | C级 | 多处不一致，影响阅读体验 | 严重修正 |
| 60以下 | D级 | 严重吃书/写崩，可能需要重写 | 重写或大修 |

## 常见吃书类型速查表

| 类型 | 典型表现 | 预防方法 |
|------|---------|---------|
| **人名吃书** | 张三/张山/张三丰 混用 | 角色名表+写前检查 |
| **时间吃书** | 昨天/上个月/三年前 混乱 | 时间线台账 |
| **地点吃书** | 瞬移、距离混乱 | 地理设定+行程记录 |
| **能力吃书** | 能力时有时无、强度忽高忽低 | 能力档案+使用记录 |
| **性格吃书** | 人设崩塌、行为不符 | 人物档案+写前对照 |
| **关系吃书** | 关系突变、称呼混乱 | 关系图谱+变化记录 |
| **设定吃书** | 世界观规则前后矛盾 | 设定档案+违反预警 |
| **道具吃书** | 物品凭空出现/消失 | 道具台账+持有状态 |
| **伤势吃书** | 伤好得太快/突然重伤 | 状态追踪+恢复进度 |
| **记忆吃书** | 角色忘了/记起不该忘的事 | 信息差管理+知情记录 |

## 检查流程

```
写完一章
    ↓
第一级：低级错误检查（30秒）
    ↓ 有问题 → 修正
    ↓ 没问题
第二级：设定一致性检查（2分钟）
    ↓ 有问题 → 修正
    ↓ 没问题
第三级：剧情连贯性检查（3分钟）
    ↓ 有问题 → 修正
    ↓ 没问题
第四级：深度一致性检查（5分钟）—— 重要章节才做
    ↓ 有问题 → 修正
    ↓ 没问题
打分 → 记录 → 更新状态
```

---

> **为什么要做一致性检查？**
>
> 读者最反感的就是吃书。一次吃书，读者对你的信任就降一分。
> 吃书多了，读者就弃书了。
>
> AI 因为没有真正的"记忆"，特别容易吃书。
> 这份清单就是 AI 的"外置记忆"——写完对照一遍，大多数吃书都能避免。
